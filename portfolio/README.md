# Your Name | Personal Portfolio Website

A responsive, four-page portfolio built with HTML5, CSS3 and Bootstrap 5.

**Live site:** https://your-username.github.io/yourname-portfolio-website/

## Pages

- `index.html` Home (hero, highlights)
- `about.html` About (biography, education, skills, interests)
- `gallery.html` Gallery (motivation video, photo grid)
- `contact.html` Contact (details, form, map)

## Before you publish

1. Replace "Your Name", email, phone, university and social links in all four pages and `js/main.js`.
2. Add your video as `video/motivation.mp4`.
3. Replace the placeholder images in `images/` with your own photos (keep the file names, or update the `<img>` tags).
